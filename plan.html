FATAL Технические ошибки в описаниях покрытий

  • Хромирование: НЕ делаем декоративное хромирование бамперов и мототехники — это вакуумное напыление. Есть 3 вида хрома: молочное, твёрдое, декоративное по подслою никеля.
  • Никелирование: в цепочке «подслой под серебро» неправильная последовательность. Реально: хим.никель по алюминию → медь → серебро.
  • Серебрение: сайт называет «реставрационным». На деле — электролит без блескообразующих добавок, применяется для повышения электропроводности.
  • Меднение: как «реставрационный вариант» не применяется — быстро окисляется. «Состаренную медь» не делают.
  • Оловянирование: «пищевая безопасность» — неправда. Наше олово — техническое, безопасность контакта с пищей под вопросом.

FATAL Неправильные факты про сертификацию и лабораторию

  • Лаборатория НЕ аккредитована. Проводит анализ и корректировку гальванических ванн (внутренний контроль), а не испытания. Убрать «толщинометрию каждой партии», «коррозионную стойкость» из блока контроля.
  • Паспорта качества выдаются не на каждую партию, а по запросу заказчика. Замеры толщины на каждую партию не предоставляют.
  • ISO указано неправильно. Правильно — есть отдельная сертификация СМК:
    • ГОСТ Р ИСО 9001-2015 + ГОСТ РВ 0015-002-2020 (сертификат № СДС ВС 01.1930-2023, до 16.08.2026)
    • ГОСТ Р ИСО 14001-2016 экологический менеджмент (сертификат № СДС ВС 06.092-2023, до 29.06.2026)

FATAL Цвета покрытий в 3D-модели отображаются некорректно

Клиент явно указал на это. Нужно перекалибровать материалы для хрома / никеля / серебра / олова.

— имеется ли на данный момент старое покрытие / окалина / загрязнения, которые необходимо удалить перед нанесением нового покрытия.

Технически

  • Поле загрузки — multi-file (не один файл, а много чертежей на разные детали за одну заявку)
  • Возможность добавлять несколько позиций (deatils) в одну заявку
