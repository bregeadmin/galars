# Админка «правка на сайте» — спека (2026-09-15)

Решения Артёма: фото перетаскиванием, любой текст, вход по паролю, публикация сразу по кнопке, сервер — Supabase (переезд на Yandex Cloud возможен: функция переносимая).

## Для редактора
`galars.ru/?edit` → пароль → тексты редактируются на месте (рамка при наведении), картинки и рамки-заглушки `.ph-card` принимают фото перетаскиванием, полоска внизу: «Изменено: N · Опубликовать · Отменить · Выйти». После публикации сайт обновляется за 1–3 мин (GitHub Pages). Только десктоп.

## Части
1. **Метки** — `tools/mark-editable.py` ставит `data-e="<page>#<n>"` на h1–h4, p, li, dt, dd, figcaption, td, th (только внутренние, с текстом; не в header/nav/footer/script/template; не элементы с `id`), на `img` (кроме логотипов/иконок) и на `.ph-card` (слоты фото, `data-kind="slot"`). Идемпотентен. Добавляет `<script src="edit-boot.js" defer>` на страницы.
2. **Редактор** — `edit-boot.js` (грузит `edit.css`+`edit.js` только при `?edit`), `edit.js`: логин, contenteditable, перехват Enter→`<br>`, вставка как текст, отключение переходов по ссылкам, drag-drop фото с ужатием в браузере (≤1600px, JPEG ~0.82), очередь изменений, публикация постранично.
3. **Сервер** — Supabase Edge Function `galars-publish` (Deno, без зависимостей): `login` (пароль → токен HMAC на 12 ч, лимит попыток по IP), `publish` (токен → берёт файл страницы из GitHub, меняет только блоки по `data-e`, санитизация HTML по белому списку, фото в `img/uploads/`, один коммит через Git Data API). Секреты: `GITHUB_TOKEN` (fine-grained, contents:write на bregeadmin/galars), `PASSWORD_HASH` (sha256(password+PEPPER)), `PEPPER`, `ALLOWED_ORIGINS`.
4. **Поиск** — GitHub Action `.github/workflows/search-index.yml`: на push *.html пересобирает `search-index.json` и коммитит.
5. **Слоты фото** — `shared.css`: `.ph-card.has-photo` (фото cover + подпись материала поверх).

## Не в первой версии
Новые страницы/секции, добавление 13-го фото в «Работы», форматирование текста, несколько пользователей, откат кнопкой (есть git).

## Безопасность
Ключ GitHub и хэш пароля — только в секретах функции. CORS — только домены сайта. 5 неудачных попыток → 15 мин блокировка IP. Санитизация HTML на сервере.
